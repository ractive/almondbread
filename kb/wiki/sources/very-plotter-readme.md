# Very Plotter (visualize-primes) README

**URL:** <https://raw.githubusercontent.com/philthompson/visualize-primes/master/readme.md> · **Saved:** `raw/web/very-plotter-readme.md` · **Terms:** MIT (repository licence)

## What it is

The short README of Phil Thompson's GitHub repository `visualize-primes`, which hosts Very Plotter, a browser (JavaScript) Mandelbrot explorer that began as a prime-number plotter.

## What it covers

- Very Plotter is a full-window Mandelbrot explorer in JavaScript, with perturbation theory and series approximation for deep zooms.
- The latest release is served from the author's blog (philthompson.me/very-plotter), not from GitHub releases.
- Points to two background posts: "The Mandelbrot set on Very Plotter" (2021) and "Perturbation Theory and the Mandelbrot set" (2022).
- Licence: MIT.
- It does not mention BLA, which was added later in v0.10.0 (see [Phil Thompson: Faster Mandelbrot set rendering with BLA (2023)](philthompson-bla.md)).

## Reliability

Primary but minimal. The README lags the code: it lists perturbation and SA only. Repository last pushed 2023-05-09 (brief, gh api 2026-10-14).

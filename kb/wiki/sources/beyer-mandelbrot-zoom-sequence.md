## What it is

The 15-image zoom sequence (Ultra Fractal 3, 2005) that illustrates Wikipedia's
Mandelbrot set article ("Image gallery of a zoom sequence"). Each file description gives
the image centre, its *horizontal* diameter (800x600 images, so the shorter side is 0.75 of
it) and the magnification relative to the first image.

## Reliability

Primary for these views: the author's own parameter values. Captions describe what each
image shows (Misiurewicz point at the seahorse tail's end, satellites, crowns whose
number doubles); the descriptions are not quoted elsewhere in this wiki.

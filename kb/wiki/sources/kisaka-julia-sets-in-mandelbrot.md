# Kisaka: Julia sets in the Mandelbrot set and small Mandelbrot sets

**URL:** <https://www.math.kyoto-u.ac.jp/en/node/2851> · **Not saved** (read 2026-10-15) ·
Kyoto Dynamical Systems Seminar, 2015-11-20 (abstract only).

## What it covers

The phenomenon the journey's "embedded Julia" targets rely on, stated by a mathematician:
zooming into a part of the Mandelbrot set first shows a figure J' very similar to a Julia
set; zooming further into its middle shows a nested structure similar to the iterated
preimages of J' under `z²`, and finally a small Mandelbrot set M' appears. The talk
formulates and proves this and shows the same nesting in Julia sets for parameters inside M'.

## Reliability

Abstract only (the talk is not published here); it confirms the order of the stages, not
their sizes. For sizes see [Mu-Ency: Newton-Raphson zooming (embedded Julia set sizes)](muency-newton-raphson-zooming.md).

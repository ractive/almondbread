# Bevy 0.20 release notes

**URL:** <https://bevy.org/news/bevy-0-20/> · release history <https://bevy.org/news/>

## What it is

Release notes of Bevy 0.20 (2026-10-08), the Rust ECS game engine built on wgpu.

## What it covers

- 227 contributors, 817 PRs; Solari path tracer, DLSS-RR via `dlss_wgpu`, mesh shaders, Feathers widgets.
- Adopted WESL: custom shaders must be renamed `.wgsl` to `.wesl`; BSN scene changes; no editor ships.
- Seven releases from 0.14 (2024-07) to 0.20, still pre-1.0.

Primary project announcement. Compute-shader ergonomics are not covered.

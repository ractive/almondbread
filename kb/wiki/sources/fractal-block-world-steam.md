# Fractal Block World (Steam store page and reviews)

**URL:** <https://store.steampowered.com/app/1540570> · reviews API <https://store.steampowered.com/appreviews/1540570?json=1&language=all&purchase_type=all> · [SteamSpy](https://steamspy.com/app/1540570) (fetched 2026-10-14)

## What it is

Store page and review data of Fractal Block World, a $6.99 Windows "surreal exploration game" where "you can shrink infinitely to go deeper into the fractal". Released 18 Oct 2021 after early access.

## What it covers

- 1,652 reviews, 98.2% positive ("Overwhelmingly Positive"); SteamSpy 50k–100k owners, peak 72 concurrent on its snapshot day.
- Reviewers praise 16–50+ hours, an ending, replays and secrets; one says the trailer is "completely inadequate".
- Grew from the Block Arena / Infinifrag 2 codebase (about 2008 onward), so roughly a decade of work.

## Reliability

Live Steam data; owner counts are estimates. The only fractal game on Steam with real traction, so the main comparable for a game edition.

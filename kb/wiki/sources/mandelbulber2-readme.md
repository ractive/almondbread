## What it covers

- "Official repository for Mandelbulber v2": open-source 3D fractal renderer for trigonometric,
  hypercomplex, Mandelbox, IFS and other 3D formulas.
- "Complex 3D raymarching" with hard shadows, ambient occlusion, depth of field, refraction;
  "multi-GPU support via OpenCL"; key-frame animation for all parameters.
- GPL-3.0; Linux, Windows, macOS (ARM support experimental); ~8 000 commits, 1.1 k stars.

## What it is

A sans-serif designed for screens; static TTFs in nine weights plus a variable font, with
Latin, Greek (λ, μ, π) and the arrows and maths symbols the overlay prints. Digits are
proportional by default (tabular figures are an OpenType feature), so our layout centres
digits on a common advance instead ([Overlay text: SDF font atlas in Rust and Metal](../platform/overlay-text.md)).

## Used for

The overlay font atlas ([Overlay text: SDF font atlas in Rust and Metal](../platform/overlay-text.md)): SemiBold, 109 glyphs, as a signed
distance field generated by `crates/almondbread-render/examples/gen_overlay_font.rs`.

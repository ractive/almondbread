# Wikipedia: Mandelbox

**URL:** <https://en.wikipedia.org/wiki/Mandelbox> · read 2026-10-19, not saved

## What it covers

- Found by Tom Lowe in 2010. Each iteration reflects components beyond ±1 (box fold), rescales
  the magnitude (×4 below 0.5, inversion between 0.5 and 1: the ball fold), then
  `z = scale·z + c`. The set is the `c` whose orbit from the origin stays bounded; defined in
  any dimension; "a map of continuous Julia sets".
- For `1 < |scale| < 2` it has a solid core; at scale −1.5 it contains approximations of many
  known fractals; side length formulas for several scale ranges.
- Nothing on rendering, distance estimation, precision or depth; the article is flagged for
  relying on primary sources.

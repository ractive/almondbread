## What it is

The README of Fractalshades (GitHub `GBillotey/Fractalshades`, MIT, pushed 2026-08-30), a Python package for deep-zoom fractal rendering with a PyQt6 GUI.

## What it covers

- Purpose: "efficient algorithms for static and interactive deep-zoom exploration (1.e-2000 and beyond) of a few fractals".
- GUI built with PyQt6 (screenshot dated 2022-02-04).
- CI badges for Linux and Windows tests and a Windows build; documentation at gbillotey.github.io/Fractalshades-doc.
- No algorithm details; the documentation site is not saved.

## Reliability

Primary but minimal. The depth claim (1e-2000) is unquantified: no timings, no named methods.

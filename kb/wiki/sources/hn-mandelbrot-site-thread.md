# Hacker News: Mandelbrot Set Explorer thread (2025)

**URL:** <https://news.ycombinator.com/item?id=43375676>

## What it is

The March 2025 HN thread on mandelbrot.site (86 points, 43 comments). The same site's own Show HN in October 2024 got 5 points (<https://news.ycombinator.com/item?id=41720454>).

## What it covers

- Demand: "I thought I could zoom in forever"; "Zoom is jerky and the number of iterations don't automatically scale"; requests for a fast native program (answers: XaoS, Fractint).
- Users mistake low-iteration blobs for bugs; ask for stable colouring when iterations change; praise live Julia previews (mandel.gart.nz).
- Users pass exact locations to each other as URLs.

## Reliability

Anecdotal comments from a technical audience; useful for qualitative demand, not for sizing.

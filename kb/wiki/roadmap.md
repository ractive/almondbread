# Roadmap

Milestone status for almondbread. Derived from the ranked roadmap in
[Deep zoom Mandelbrot rendering techniques](synthesis/deep-zoom-rendering-techniques.md); updated by the driver session
as milestones start and finish.

> **Priority (user, 2026-10-14):** feel and look first. Flying must feel
> and look stunning at shallow depth before any more depth or game work;
> if it does not, the game makes no sense. Order: M2.5 → FL (feel & look)
> and L0 → user review gate → L1 (real-time landscape prototype, if L0
> convinces) → user review gate → M3b, M4, M6, product and game features.

**Fractal types (2026-10-19).** F1–F8 and BB replace the old M8 ("more formulas via an opcode
model", now F7). Order and reasons: [Other fractal types: what almondbread could support, at what cost](synthesis/other-fractal-types.md) §5; one plan page per
milestone under `plans/` (`hyalo find --view plans`). Mandelbrot stays formula 0: every formula
milestone must show bit-identical Mandelbrot fields and a `bench` A/B geomean ≈ 1.0. True 3D
("3D worlds", Mandelbox first) is not on the roadmap: not recommended now, see
[3D worlds (Mandelbox first): not recommended now](plans/3d-worlds.md) and [Ideas](ideas.md); the 2.5D landscape (L0–L2) is the cheaper route.

thresholds (I2), the tours (T1) or the walkthrough (T2).
